# Редактор сайта ЖАТ — проект системы управления

## Цель и границы

Сохранить публичные 79 пунктов меню, страницы, новости, архив, поиск, документы, видео, контакты и доступность. Добавить редактор, в котором сотрудник публикует новости и обновляет страницы без работы с HTML, FTP и Joomla. Существующие публичные материалы остаются базовой копией; правки редактора имеют приоритет. Черновики не видны посетителям.

Фотографии подтверждают Joomla 3.10.12 с менеджерами материалов, категорий, меню, медиа, пользователей и расширениями JEvents, Smart Slider 3, Ignite Gallery, eXtplorer и другими. Фотографии не дают ни доступа к базе, ни содержимого скрытых модулей. Их нельзя считать доказательством завершённой миграции этих данных.

## Решение

- Node.js 24 + встроенная SQLite, постоянное хранилище в `.data/`. Сервер обслуживает сайт, публичный API и админку. Существующий статический пакет остаётся для показа и как резервная копия материалов.
- Вход по индивидуальному паролю; роли «администратор» и «редактор». Сессия хранится на сервере, cookie HttpOnly, проверка CSRF и ограничение попыток входа. Первый администратор создаётся однократным кодом запуска, который не попадает в Git.
- Базовые страницы и архив новостей импортируются из уже сохранённого публичного каталога. Новые и изменённые записи хранятся отдельно, с версиями и датой публикации. Черновик существующей страницы оставляет опубликованную версию видимой.
- Панель: обзор, список новостей и страниц, визуальный редактор, загрузка файлов, настройки меню, сотрудники. Кнопки и подсказки называют действия человеческим языком.
- Меню можно упорядочить и дополнить новыми страницами. Старый URL сохраняется при редактировании страницы; новые страницы получают собственный адрес. Новости попадают на главную и в архив сразу после публикации.
- Загружаемые изображения и документы остаются в `.data/uploads/`; база и файлы требуют общего резервного копирования. Нет выдуманного содержимого пустых страниц старого сайта.

## Миграция и эксплуатация

Начальное состояние строится из сохранённого публичного каталога. Для закрытых материалов Joomla, исторических файлов и настроек расширений нужен отдельный экспорт базы и медиа. Перед переключением официального домена требуется проверка URL, прав доступа, форм и процедур согласования со стороны техникума. Локальный рабочий редактор сам по себе не переключает `zhat.ru` и не заменяет сторонние сервисы, к которым нет доступа.

## Проверка

Проверить вход, роли, черновик/публикацию, обновление уже существующей страницы, появление новости на публичном сайте, загрузку файла, управление меню, восстановление версии, блокировку неавторизованных запросов и мобильный экран. Сохранить старые тесты импорта и упаковки.
