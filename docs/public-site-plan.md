# Полнота публичного сайта ЖАТ

Цель: сохранить дизайн и сделать доступными публичные сценарии оригинала в новом интерфейсе, включая мобильный просмотр.

Причина пробелов: App показывает только лендинг; data.js содержит фиксированный каталог и 3 новости; остальные ссылки ведут на оригинал.

Решение: безопасный импорт публичного контента, локальные страницы с адресами и историей переходов, каталог разделов и поиск; материалы и формы колледжа сохраняют оригинальные адреса. Новая навигация использует импортированные страницы. Новости обновляются при синхронизации перед запуском/сборкой. Импорт не выполняет исходные скрипты и не переносит чужие формы/учётные записи.

План:
1. Получить меню, публичные страницы и новости; очистить HTML по списку разрешённых тегов/атрибутов; записать отчёт ошибок.
2. Добавить маршрутизацию, каталог, поиск, новости, страницы и удобное мобильное меню; исправить телефон.
3. Связать существующие кнопки с новыми страницами; сохранить внешние официальные сервисы и документы.
4. Проверить импорт, ссылки, сборку, поиск, переходы и телефонный экран.

Ограничения: закрытая Joomla-админка, публикация на zhat.ru и обработка обращений требуют доступа колледжа. Публичные формы открываются у действующего провайдера. Недоступные исходные страницы показываются с честным состоянием и ссылкой на оригинал. Архив не объявляется полным без полного переноса.

Риски: устаревание копии; несовместимость исходных виджетов; большие таблицы. Защита: дата синхронизации, оригинальная ссылка, адаптивные таблицы, whitelist HTML, тесты на активное содержимое.

Откат: резервная копия src в /tmp/zhat-before-public-pages; импорт/компонент Portal изолированы.
